# AI Contract Analyzer

A production-ready AI-powered Contract Analyzer built with FastAPI, Next.js, PostgreSQL, LangChain, ChromaDB, and OpenAI.

## Features

- Upload PDF/DOCX contracts
- AI-generated summaries
- Clause detection
- Missing clause analysis
- Risk assessment
- RAG-based question answering
- Version history (planned)
- Multi-user support (planned)

## Tech Stack

### Frontend
- Next.js 15
- React
- TypeScript
- Tailwind CSS
- Shadcn UI

### Backend
- FastAPI
- SQLAlchemy

### AI

- OpenAI
